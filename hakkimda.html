Burak Can Balta

Uludağ Üniversitesi Fizik Bölümü öğrencisiyim ve siber güvenlik alanında offensive security odaklı olarak kendimi geliştiriyorum. Web application security, Active Directory pentest ve exploitation üzerine uygulamalı deneyim kazanıyor, güvenli yazılım geliştirme pratiklerini takip ediyorum.

Şu anda BgTek Cyber Security bünyesinde Penetration Tester stajyeri olarak gerçek saldırı senaryoları üzerinde çalışıyorum. Bunun yanında Siber Vatan ve UluSiber (Uludağ Üniversitesi Siber Güvenlik Topluluğu) çatısı altında teknik ekip üyesi olarak aktif rol alıyor, GitHub üzerinde güvenlik odaklı araçlar geliştirerek farklı saldırı senaryolarını ve savunma mekanizmalarını uygulamalı olarak analiz ediyorum.

Şu anda OSCP'ye hazırlanıyorum. Düzenli olarak Hack The Box ve TryHackMe üzerinde CTF/lab çözüyor; teknik yetkinliğimi gerçekçi saldırı senaryoları, araç geliştirme ve writeup/makale çalışmalarıyla sürekli geliştiriyorum.

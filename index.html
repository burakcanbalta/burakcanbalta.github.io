Burak Can Balta

Uludağ Üniversitesi Fizik öğrencisiyim, siber güvenlik alanında teknik gelişimime odaklanıyorum. Web application security ve offensive security prensipleri üzerine çalışıyor, güvenli yazılım geliştirme pratiklerini takip ediyorum. GitHub üzerinde güvenlik odaklı araçlar geliştirerek farklı saldırı senaryolarını ve savunma mekanizmalarını uygulamalı olarak analiz ediyorum.

Frontend ve backend geliştirme bilgimi güvenlik perspektifiyle birleştirerek uygulama güvenliği ve saldırı yüzeyi analizi üzerine çalışıyorum. Şu anda OSCP'ye hazırlanıyor, düzenli olarak CTF çözüyor; öğrendiklerimi writeup ve makaleler halinde bu sitede yayınlıyorum.
